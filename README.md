# LIRA

### Local Independent Resource for Artists

> **Your art. Your identity. Your space.**

LIRA is an open-source portfolio platform designed for local and independent artists to create, customize, and share their own online creative space.

Instead of relying entirely on social media profiles, artists can build a dedicated portfolio that brings their work, identity, links, and contact information together in one place.

## ✨ Vision

LIRA aims to give independent artists a simple and customizable way to build their presence on the web.

Artists should be able to:

- Create an artist profile
- Build a personal portfolio
- Showcase projects and creative work
- Add images, videos, music, and external links
- Customize their portfolio's appearance
- Choose from different portfolio themes
- Organize and reorder portfolio sections
- Preview changes before publishing
- Publish a shareable public portfolio
- Share their portfolio through social media

## 🚀 Project Status

**Early Development**

LIRA is currently under active development. The initial focus is building the core portfolio creation, customization, and publishing experience.

Features and architecture may change as the project evolves.
